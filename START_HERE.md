## 👋 Welcome

The **DLT Chat Plugin** is a smart tool for analyzing DLT (Diagnostic Log and Trace) files using natural language queries.

**Ask questions like:**
- "Show me all errors"
- "Find CAN bus messages"
- "What are the timeout issues?"
- "Give me a summary"

And get instant answers with direct navigation to log entries!

## ✨ Key Features

✅ **Natural Language Queries**  
Ask questions about your DLT logs in plain English (or Italian, German, Spanish, French)

✅ **Instant Results**  
Get matching log entries with direct navigation

✅ **CSV Export**  
Export your analysis results to CSV for sharing

✅ **Dual Analyzers**  
- Rule-based (fast, no setup)
- AI-powered (using Ollama/OpenAI/LocalAI)

✅ **Multi-Language**  
English, Italian, German, Spanish, French

✅ **Well Documented**  
8 comprehensive guides + code examples

## 🔧 System Requirements

**To Use:**
- DLT Viewer 2.30.0+
- Qt 5.15.x or 6.x

**To Build:**
- CMake 3.16+
- C++17 compiler
- Qt development libraries

**Supported Platforms:**
- Linux (Ubuntu 20.04+)
- Windows 10/11
- macOS (experimental)
